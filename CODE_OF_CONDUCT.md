# Código de Conducta para Contribuyentes

Este proyecto adopta el Contributor Covenant. Esperamos un comportamiento respetuoso y profesional.

- Sé amable y empático.
- Acepta críticas constructivas.
- Enfócate en lo que es mejor para la comunidad.

Para reportar conductas inadecuadas, abre un issue o contacta a los mantenedores a través del repositorio.
